# 电源管理集成电路 (PMIC)

## 概述

电源管理集成电路（PMIC, Power Management Integrated Circuit）是电子系统的"心脏和血管"，负责将电池或外部电源的电压转换为芯片所需的各种稳定电压轨，同时对电源进行监测、保护和动态调节。PMIC 涵盖了 DC-DC 转换器（Buck/Boost/Buck-Boost）、低压差线性稳压器（LDO）、电池充电管理、电源路径管理、电压监测与复位等功能模块。从手机 SoC 中的数十路电源轨，到数据中心 AI 芯片的数百安培核心供电，PMIC 决定了整个系统的能效、可靠性和热特性。

## 核心原理

电源管理的基本矛盾是**效率与精度的折中**：

**开关电源（DC-DC）** 通过电感和电容储能元件，以高频开关方式将输入电压转换为所需输出电压。理想开关不消耗功率（电压×电流 = 0），因此理论效率可达 100%，实际受限于开关损耗、导通损耗和磁性元件损耗。Buck 拓扑（降压）是使用最多的架构：Vout = D × Vin，其中 D 为开关占空比。

**线性稳压器（LDO）** 通过调整串联调整管的等效电阻（工作于线性区），使输出电压稳定在设定值。LDO 的优点是低噪声、快瞬态响应、无 EMI，但效率理论上不超过 Vout/Vin，输入输出压差大时效率极低。通常用于对噪声敏感的模拟/RF 供电。

**多相位交错（Multi-phase）** 在大电流场合（>100A），将功率级拆分为多个并行相位，错相导通，等效开关频率 N 倍提升，纹波电流抵消。这是 AI 芯片核心供电（Vcore）的标准方案。

## 关键技术

**先进工艺与集成**：PMIC 正从传统的 0.18μm BCD 工艺向 90nm/55nm BCD、甚至 FinFET 兼容的功率工艺迁移。高密度集成数字控制、PMBus/I²C 通信接口和功率级。

**数字电源控制**：数字控制环路（PID/非线性控制）替代传统模拟补偿网络，提供自适应环路带宽、快速瞬态响应和在线效率优化。全数字电源可通过固件升级改变控制策略。

**宽禁带功率级**：GaN FET 替代硅 MOSFET 构成的高频 DC-DC 转换器（1 MHz+），极大减小无源元件尺寸。SiC 在高输入电压（48V→1V）的两级供电架构中发挥优势。

**48V 供电架构**：AI 数据中心从 12V 总线向 48V 迁移，减小 I²R 损耗。48V→1V 直接转换需要高降压比架构：开关电容 + 变压器谐振型（如 TLVR）的混合架构。

**集成电压调节器（IVR）**：将电源转换器直接集成到 SoC die 或 package 上，用电感/电容的片上集成或封装集成实现亚纳秒级电压调节，支撑 DVFS 和功耗管理。

## 代表性工作

| 成果 | 机构 | 主要贡献 |
| --- | --- | --- |
| 多相数字 Buck | Infineon / TI | 服务器/AI 芯片 Vcore 供电主力，支持 1000A+ 电流 |
| 高频 GaN DC-DC | EPC / TI | GaN FET 实现 MHz 级开关，电流密度 ~1A/mm² |
| 全集成 IVR | Renesas / Intel | 封装集成电压调节器，~10ns 瞬态响应 |
| 48V→1V 直接转换 | Vicor (SAC) | 正弦振幅转换器，>96% 效率，400A |
| 手机 PMIC | Qualcomm / Dialog | 单片集成 20+ 电源轨、充电管理、LED 驱动 |

## 应用场景

- **智能手机**：SoC 多路 DVFS 供电、快充管理、电池保护
- **数据中心 / AI 加速器**：GPU/AI 芯片的大电流 Vcore/SRAM 供电
- **汽车电子**：48V 混动/电动系统、ADAS、域控制器供电
- **IoT / 可穿戴**：超低静态电流（nA 级）、能量采集供电
- **医疗设备**：高可靠性、低噪声、隔离电源

## 发展趋势

- **TLVR（跨电感电压调节器）**：面向下一代 GPU/AI 芯片的超高 di/dt 瞬态供电架构
- **48V 直转 + 两级架构融合**：AI 机架能效优化的核心电源架构
- **PMIC + 功率级单片集成**：BCD 与 CMOS 的深度融合，单芯片解决方案
- **AI 驱动的动态功耗管理**：基于负载预测的自适应电压/频率/相位调节
- **能量采集与电源管理一体**：为无源 IoT 节点提供完整的自供电方案
