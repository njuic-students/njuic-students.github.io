# 高带宽存储 (High Bandwidth Memory, HBM)

## 概述

高带宽存储（HBM）是一种通过硅通孔（TSV）技术将多层 DRAM die 垂直堆叠，并与逻辑 die（如 GPU/AI 加速器）通过硅中介层紧密互连的 3D 存储方案。相比传统 DDR/GDDR 方案，HBM 提供数量级的带宽提升（每栈 1 TB/s 以上）和显著的能效优势，是 AI 训练/推理 GPU、高性能计算 CPU 的标配内存。目前 HBM3E 已大规模量产，HBM4 标准正在制定中。

## 核心原理

HBM 的核心设计原则是**带宽 = 通道数 × 通道速率 × 利用率**。传统 DRAM 受限于 PCB 走线密度和功耗，通道数量受限。HBM 通过三维堆叠突破了这一瓶颈：

**TSV 垂直互联**：每层 DRAM die 上钻出数千个微米级通孔并填充 Cu，实现层间垂直数据传输。相比传统 wire-bond 边缘引线，TSV 极大缩短了互连距离，降低了寄生电容和功耗。

**宽 I/O 接口**：HBM 每栈提供 1024 位宽的 I/O 总线（HBM3 标准），远宽于 GDDR6 的 32 位。以较低频率即可获得超高总带宽，兼顾能效。

**硅中介层（Si Interposer）**：HBM 栈与主芯片（GPU/CPU）放置在同一硅中介层上，通过微米级金属走线互连。硅中介层的线宽/间距远优于有机基板，可在有限面积内实现数千根互连线。

## 关键技术

**多层 TSV 工艺**：在 50μm 厚的 DRAM die 上制造高深宽比 TSV（~10:1），保持信号完整性和机械可靠性。Via-middle 与 via-last 两种工艺流程各有千秋。

**微凸点键合与混合键合**：DRAM die 间通过微凸点（~25μm 间距）实现电气和机械连接。混合键合（Cu-Cu + SiO₂-SiO₂）可进一步缩小间距至 <10μm。

**热管理**：HBM 栈的垂直结构使热量集中在靠近逻辑 die 的底层 DRAM。需要先进的 TIM（热界面材料）、散热盖和微流道方案控制 DRAM 结温。

**PHY 与控制器设计**：HBM PHY（物理层）需实现精确的时钟同步、信号均衡和功耗管理。Each channel 独立操作，2.5D 布局对信号完整性要求极高。

**ECC 与可靠性**：HBM3 引入了增强的片上 ECC、错误检查和清理机制，保障 HPC/AI 负载下的数据完整性。

## 代表性工作

| 成果 | 机构 | 主要贡献 |
| --- | --- | --- |
| HBM Gen1 (2013) | AMD / SK Hynix | 首款商用 HBM 产品，4 层堆叠，128 GB/s |
| HBM2E (2018) | Samsung / SK Hynix | 8 层堆叠，460 GB/s，单 die 16Gb |
| HBM3 (2022) | SK Hynix / Samsung | 12 层堆叠，819 GB/s，单 die 24Gb |
| HBM3E (2023) | SK Hynix / Samsung / Micron | 9.6 Gbps/pin，1.2 TB/s，AI 训练主力 |
| HBM4 (推进中) | JEDEC 标准 | 2048-bit 接口，逻辑 die 独立设计 |

## 应用场景

- **AI/ML 加速器**：NVIDIA H100/B200、AMD MI300X 等均搭载 HBM
- **高性能计算（HPC）**：科学仿真、气候建模等内存带宽敏感场景
- **网络交换芯片**：高速交换机/路由器需大量缓存
- **FPGA 加速卡**：Xilinx Versal HBM 系列集成 HBM
- **图形渲染**：高端 GPU 的大容量纹理和帧缓存

## 发展趋势

- **逻辑 die 独立设计**：HBM4 将逻辑基础 die 与 DRAM 栈解耦，客户可定制逻辑 die
- **12 层→16 层堆叠**：更高层数带来更大容量和带宽
- **混合键合替代微凸点**：进一步降低间距和功耗
- **存内计算（PIM）**：在 HBM 的 DRAM die 中嵌入计算单元，减少数据搬运
- **3D + 2.5D 融合**：HBM 3D 堆叠与逻辑芯片的 3D IC 集成趋势
