# 先进制程与晶体管 (Advanced Process & Transistors)

## 概述

先进制程与晶体管技术是集成电路制造的基石，决定了芯片的性能、功耗和面积（PPA）。从平面 MOSFET 到 FinFET，再到如今的 GAA（Gate-All-Around）纳米片晶体管，每一次器件结构的革新都推动摩尔定律的延续。当前台积电、三星、Intel 已进入 3nm 及以下节点，CFET（互补 FET）等下一代器件也在研发中。先进制程不仅关乎晶体管尺寸微缩，更涉及材料工程、光刻技术、3D 集成等系统性创新。

## 核心原理

晶体管的本质是**场效应调控**：栅极电压控制沟道中的载流子浓度，从而调控源漏电流。传统平面 MOSFET 在沟道长度缩至 20nm 以下时，短沟道效应（SCE）加剧——漏致势垒降低（DIBL）、亚阈值摆幅退化，导致关态漏电流指数上升。

**FinFET** 通过将沟道"竖起来"形成鳍状结构，使栅极三面包围沟道，增强了栅极对沟道的静电控制。**GAA / 纳米片晶体管**进一步将沟道完全包裹，栅极从四面控制，实现近乎理想的静电完整性，可将沟道长度进一步微缩至 10nm 以下。

## 关键技术

**极紫外光刻（EUV）**：采用 13.5nm 波长光源，实现单次曝光 30nm 以下线宽；High-NA EUV 将数值孔径从 0.33 提升至 0.55，分辨率进一步突破。

**高 k / 金属栅（HKMG）**：以 HfO₂ 等高 k 材料替代 SiO₂ 栅介质，增大物理厚度以抑制隧穿漏电，同时保持等效氧化层厚度（EOT）极小。金属栅极避免多晶硅耗尽效应。

**应变硅技术**：通过在沟道中引入应力（SiGe 源漏嵌入、应力衬垫氮化硅），拉伸或压缩晶格，提升载流子迁移率。

**3D 集成与背面供电**：BSPDN 将电源网络移至晶圆背面，释放正面信号走线空间，同时降低 IR Drop。

## 应用场景

- **高性能计算（HPC）**：CPU/GPU 微缩带来更高的晶体管密度和频率
- **移动 SoC**：先进制程是智能手机芯片功耗控制的关键
- **AI 加速器**：大算力训练/推理芯片对晶体管密度需求极高
- **车规芯片**：先进制程与成熟制程的可靠性权衡

## 发展趋势

- **CFET 与 3D 堆叠晶体管**：垂直集成互补 FET，密度翻倍
- **背面供电网络（BSPDN）**：彻底改变芯片物理设计
- **二维材料沟道**：MoS₂ 等超越硅的原子级厚度沟道
- **DTCO / STCO**：设计-工艺协同优化，跨层级联合设计
- **超越 CMOS**：隧道 FET、负电容 FET 等新型开关机制
