# 香港科技大学 ECE 提前批（EAS）

## 基本信息

港科大**电子与计算机工程学系**（Department of Electronic and Computer Engineering, **ECE**）的 **PhD Early Admission Scheme（EAS，提前批）**。和常规申请不同，它走的是**本科院校推荐制**：先由本院筛选推荐 **2–4 位**同学（每年人数不定）给港科大，再由 ECE 组织**两轮全英文面试**，通过后发提前批录取，最后才由系里协调导师匹配。

关键节点（以 2026 年这一轮、2027/28 入学为例）：

| 时间 | 事项 |
| --- | --- |
| 4 月前 | 报名；由**本科院校筛选并推荐 2–4 位**优秀同学给港科大 |
| — | 被推荐同学填写报名表（**需填 3 位意向导师**） |
| — | **第一轮面试**：线上，全英文 |
| — | **第二轮面试**：线下，港科大校园，3 天 |
| 二面后约一周 | 发提前批录取通知（本届要求 7 月 12 日前回复是否接受） |
| 接受 offer 后 | 提交《Supervisor Matching Intention Form》（本届 ddl 为 8 月 3 日） |
| 表格 ddl 后 | ECE 系与导师商量匹配结果，匹配成功会邮件通知 |
| 之后 | 进入系统开放的**正式申请**阶段 |

- ECE EAS 邮箱：`eceeas@ust.hk`
- ECE 师资列表：<https://ece.hkust.edu.hk/people_list>
- 港科大 ECE 在 AI/具身/架构/数字/模拟/射频/器件方向都有对应老师。

## 考核环节

### 第一轮面试（线上）

- **全英文**。面试官**大概率是你报名表里 3 位意向导师中的一位，且大概率是排第一的那位**。
- 流程基本是：自我介绍 → 考官提问。**面试氛围完全取决于面试官个人**。
- 因为是线上，**可以共享屏幕放 PPT 讲项目**；建议提前做一份精简的项目 PPT（讲清楚项目背景、方法、结果即可）。
- 从本院同学的经验看，一面主要是**背景面（bg 面）**：有国家奖学金和不错的排名，基本都能过。

**实际被问到的题目（回忆版）**

项目相关的专业课问题：

- HFSS 和 Cadence 的 EMX 有何区别？
- FPGA 和 CPU 的异同与侧重点？
- MOS 管小信号模型为什么是「**受控电流源 ∥ 沟道调制电阻**」的**并联**结构？能画成**串联**等效吗？如果能，什么场景需要这样画？

例行提问：

- 你最想做什么方向？
- 港科大是你的第几选择？
- 如果发 offer，你来的概率有多大？
- 如果你想做的方向的老师没给你 offer，你愿意换方向吗？

### 第二轮面试（线下 · 港科大校园，3 天）

- 港科大**包机酒**（往返机票与住宿由学校承担）；第一天没有安排。
- 第二天先报到，随后**分两组**：一组先参观实验室、另一组面试，之后对调。
- **2026 年共 37 人**进入二面，其中**南大 7 人**。
- 二面**面试官 2 人**，与一面不同；氛围同样因人而异——据南大同学反馈，有的组问得很细致，有的很温和。
- 现场**没有 PPT、也没有电脑**：可以带几份**英文 CV**（面试官 2 人，建议带 3–5 份），自我介绍与项目讲解全靠口述。
- 下午是校园参观（香港真的很热）。
- 参观结束有**师生交流环节**，可以主动找意向导师面谈，这是刷脸、确认方向的好机会。

### 录取与导师匹配

- 二面结束后**一周左右**发提前批录取。
- 选择接受后需要**提交意向导师表**；表格 ddl 结束后，**ECE 系会与导师商量匹配结果**。
- **表格 ddl 前后都可以继续套磁**；匹配成功会有邮件通知。
- 匹配完成后，才是系统开放的正式申请阶段。

## 准备建议

1. **一面是背景面，但不要只靠背景**：成绩（国奖、排名）是敲门砖，项目还是会被追问到专业课层面——上面那三道题都是"项目里用到的东西，往原理上再问一层"。
2. **专业课基础要能现场画、现场推**，尤其是小信号模型、等效电路变换、工具之间的区别（HFSS vs EMX、FPGA vs CPU 这类对比题）。
3. **二面重点是"人"和"方向"**：师生交流环节要主动出击，提前想清楚自己想在哪个方向做什么、为什么是这个老师。
4. **套磁贯穿全程**：报名表里的 3 位意向导师、一面面试官、二面的师生交流，以及匹配 ddl 前后，都是可以沟通的窗口。
5. **材料按轮次分开准备**：第一轮线上，**可以共享 PPT 讲项目**，建议做一份精简的项目 PPT；第二轮现场**没有 PPT、也没有电脑**，带 3–5 份英文 CV 即可，讲解全靠口述，关键指标与结论要提前背熟。
6. **例行提问提前想好答案**：第几选择、来的概率、愿不愿意换方向——这几个问题答得含糊会被记住。
