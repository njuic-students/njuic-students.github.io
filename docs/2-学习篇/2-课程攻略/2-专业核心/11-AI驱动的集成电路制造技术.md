# AI驱动的集成电路制造技术

## 基本信息

课程名称：AI驱动的集成电路制造技术

课程介绍：集成电路制造工艺主干课，2025 秋起在原「集成电路制造技术」基础上加入 AI 内容。工艺部分按「绪论 → 制造流程 → 制程工艺发展 → 晶圆制造 → 外延与薄膜生长 → 光刻 → 氧化 → 刻蚀 → CMP → 掺杂 → 工艺集成 → 良率工程 → 芯片产品工程（1-3）」推进，AI 部分讲大模型发展趋势与大语言模型原理。

课程画像：

- 课程类型：核心（学科核心课程）
- 学分：3 学分
- 考核方式：平时作业（作业一～作业四）+ 期末（课件含期末复习专讲）

## 课程资料区

课程教材：

- 待补充（课件自成体系，主要是任课老师的 PPT）

参考资料：

- 课件：集成电路制造技术 1–16 讲（绪论、制造流程、制程工艺发展、晶圆制造、外延和薄膜生长一/二、光刻工艺、氧化工艺、刻蚀工艺、CMP、掺杂、工艺集成、良率工程、芯片产品工程简介一～三、期末复习）
- AI 部分：AI驱动的集成电路制造技术 6-1 大模型的发展趋势、6-2 大语言模型的理论与原理
- 作业：作业一～作业四（含一份完成版参考）

作业参考：

- 共 4 次作业（作业一～四），以工艺原理与流程分析为主。
