# 模拟电路

## 基本信息

课程名称：模拟电路

课程介绍：模拟电路的入门主干课，按「运算放大器 → 二极管 → 双极型三极管 → 场效应管 → 放大电路 → 频率响应 → 反馈 → 功率放大 → 直流稳压电源」的顺序展开，配套独立的模拟电路实验课。

课程画像：

- 课程类型：平台（学科基础课程）
- 学分：3 学分（另有独立的「模拟电路实验」1 学分）
- 考核方式：平时作业（按章布置）+ 期中/期末 + 模拟电路实验

## 课程资料区

课程教材：

- 康华光《电子技术基础（模拟部分）》第 7 版（配官方习题答案）
- 华成英《模拟电子技术基础》第 5 版（配《学习辅导与习题解答》）

参考资料：

- 课件：ch02 运算放大器、ch03～ch11（三极管、场效应管、放大电路、频率响应、反馈、功放、稳压电源等）
- 实验：实验 1、实验 2 集成运放滤波器、实验 3-2 负反馈放大电路，以及综合实验「近似方波与三角波合成」；仿真用 MultiSim（.ms14 工程）
- 复习材料：本校往年模电 PPT（含电子院版 ch01–ch11 与「半导体与PN结」专题）

作业参考：

- 按章布置作业（第二章～第十一章各有一次，以教材习题计算为主），实验课另有实验报告。

## 经验分享区

课程定位评价：

- 学科基础课，直接决定后面模拟集成电路、射频与功率集成电路、集成电路器件等课能不能学得动；模电 + 模电实验是 IC 方向最核心的基本功之一。

难度评价：

- 待补充（需要上过课的同学补一句）

作业反馈：

- 按章布置作业（第二章～第十一章各有一次，以教材习题计算为主），实验课另有实验报告。

考试情报：

- 待补充：历年期末卷在资料中留存较少，欢迎补充。

学习建议：

- 两本教材选一本精读即可（康华光偏电路应用、华成英偏器件与推导），配合「官方答案」逐题过一遍；实验部分提前在 MultiSim 里把电路跑通，现场调试会轻松很多。
