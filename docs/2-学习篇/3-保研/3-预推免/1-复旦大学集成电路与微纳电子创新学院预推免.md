# 复旦大学集成电路与微纳电子创新学院预推免

## 基本信息

复旦大学集成电路与微纳电子创新学院（原复旦大学微电子学院）是复旦集成电路方向的主力院系。预推免走复旦大学统一的推免生招生流程：先在复旦的预推免系统报名并提交材料，通过院系审核后参加复试，复试通过再在教育部研招网上完成最终填报。

### 招生方向（2026 年）

**硕士：只有专硕**，包括：

- 电子信息专硕
- 集成电路产业专项班
- 上海创芯学院联培
- 工程硕士改革专项

**博士**包括：

- 集成电路科学与工程（学术博士）
- 电子信息（专业博士）
- 集成电路产业专项班博士
- 工程博士改革专项

### 入面难度（2026 年，本院情况）

- **硕士**：强 com（委员会制），入面难度大。**普通专硕的 bar 极高**——2026 年南大集电只有 rank 2 入面；**上海创芯学院联培的 bar 低一些**，南大前 10% 即可入面。
- **博士**：弱 com（导师制），入面相对容易，但**导师话语权很大**，需要提前联系导师。笔者申请的是 **085400 电子信息（直博生）**，研究方向为**集成电路设计**。

## 材料准备

笔者实际提交的材料（具体以当年复试通知为准）：

- 本科阶段成绩单、学分绩排名证明
- 英语成绩证明（CET-6）
- 获奖证书（国家奖学金、学科竞赛获奖等）
- **个人陈述**：含个人简历、本科期间学习与科研实践、读研规划与方向匹配
- **《复旦大学推免生招生考生诚信考核承诺书》**：需本人签名，含考生报名号

::: warning 诚信考核要求（务必注意）
承诺书里明确要求：考核时**不得携带智能手表、智能眼镜等电子产品**进入考场；不得拍照、录音、录像、直播；并承诺**在复试工作全部结束前，不以任何形式透露试题内容与复试考核过程**。
:::

## 考核环节

### 面试

- **面试官 5 人左右**；面试时长由面试官决定，笔者所在的那一组时间较长。
- **不需要准备 PPT，可以携带简历**。
- 提问基本围绕**简历上的项目**展开，而且**会往细节里追问**。
- 前面有同学被要求在**黑板上画出晶体管级电路图并现场讲解**，所以基础电路（基本放大级、电流镜等）要能徒手画出来并说清工作过程。
- **博士的最终结果由导师决定**。

## 优营

- 面试结束后**3 天出结果**。
- 结果分为**待录取**和**候补**两种，其中**待录取就是铁 offer**。
- 2026 年候补环节似乎出现过一些舆情（笔者不清楚具体细节）。候补的同学建议盯紧学院与意向导师的通知，尽早主动沟通。
