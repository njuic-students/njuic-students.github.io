# 南京大学电子科学与工程学院预推免

## 基本信息
南京大学电子科学与工程学院主要包含电子工程系、微电子与光电子学系、信息电子学系、通信工程系共四个系别，该学院历史悠远，并且拥有“物理学”和“电子科学与技术”等在内的多门一级学科。

需要明确的是，硕士和博士的选拔逻辑有显著差异：
1. **硕士生**：采取**强com（委员会制）**模式。硕士主要设有无线电物理（070208）、物理电子学（080901）、电路与系统（080902）、微电子学与固体电子学（080903）、电磁场与微波技术（080904）、通信与信息系统（081001）和信号与信息处理（081002）在内的学硕专业，以及通信工程（085402）和集成电路工程（085403）在内的专硕专业。今年的复试门槛与报名时所填导师有关，笔者1专业排名12.5%成功入面了微电子学与固体电子学学硕复试，笔者2成功入面了集成电路工程专硕复试。
2. **直博生**：采取**弱com（导师制）**模式。直博需要提前联系老师，能否入营基本取决于老师意愿，但具体录取还是由导师决定。

## 考核环节
### 1. 硕士考核
#### （1）微电子学与固体电子学专业——集成电路设计方向
笔者1所报名的微电子学与固体电子学专业中，可供选择的方向包括：半导体电子器件、半导体低维结构材料与纳电子器件、集成电路设计、有机半导体材料与器件、自旋电子学材料与器件和信息光子器件与超快光源系统。
硕士生的考核流程：
- **材料准备**：笔者在收到的预推免复试通知邮件中，获悉了报到时需要准备的纸质材料非常多，大家可以把所有需要的材料整理好放入一个pdf文件中进行打印，包括：身份证复印件、学生证复印件、南京大学接收推荐免试研究生申请表（需教务签字、盖章）、本科阶段成绩单复印件、本科阶段推免学分绩排名证明（需教务盖章）、英语成绩证明、获奖证书复印件、发表论文复印件。
- **时间**：并未规定具体的面试时间，具体情况与分配的组别和老师相关
- **地点**：南京大学仙林校区电子楼
- **面试**：面试当天一般先要在报告厅候考，在此期间需要上交所有的电子设备，同时大屏幕上会显示出所有的组别，当轮到你时志愿者会带领你前往对应的考场。面试开始后，老师一般会首先要求你进行英文自我介绍，该介绍不限制时长，但不应过于冗长。随后，老师会要求你在10个PPT中（仅标号）挑选一个作为你的专业课考题，一般每个PPT会有两道题目，你可以先思考再作答。由于笔者1的报名专业，抽到的专业课考题均与半导体物理相关。在你回答完两个问题后，老师可能会针对这两个问题进一步地延申。最后，老师会针对你的简历中的某些项目进行提问（注：电子学院的面试不需要自己打印简历，他们会直接打印你提前在链接中上传的简历），并宣布面试结束。

#### （2）集成电路工程专业——高性能计算芯片方向
笔者2报名的是专硕集成电路工程专业，在专硕集成电路工程中，含有四个细分的方向，涉及数字ic，数模混合以及模拟ic相关，具体细分方向取决当年的招生细则。
硕士考核流程同微电子学与固体电子学。
以下是不同点。
- **面试**：在英文自我介绍环节，集成电路工程方向自我介绍大概率会被打断（笔者2准备的自我介绍不超过三分钟），请注意放平心态。对于抽到的专业课考题，对于高性能计算芯片方向，考题与模集，数集，数电和模电强相关，一般PPT有两道题目，可先思考再作答。随后，老师会针对你的简历提问1-2个问题，在2026年的预推免面试中，随后会进行情景问答，比如导师只让你干杂活不让发论文发专利你会怎么办。有点类似于压力面的情景问答，请注意这部分的准备。

### 2. 直博考核
笔者1和笔者2未报名南京大学电子科学与工程学院的直博预推免，考核流程暂不了解。

## 优营
笔者1收到了南京大学电子科学与工程学院的复试结果为**优先推荐**，收到邮件后可选择接受或放弃。接受后基本为铁offer，可直接在教育部研招网系统中进行最后的填报。

笔者2的补充：南京大学电子科学与工程学院的复试结果只分为两类，一类为**优先推荐**，其余均为**候补推荐**，候补学生无法得知当年的招生名额和自己的具体位次。在面试结果宣布到最终填研招网系统确认的时间，电子院教务处会根据优营的放弃情况打电话通知候补同学，在电话中同意可直接在教育部研招网系统中进行最后的填报。在2026年的推免招生中，南京大学会在研招网系统中给所有人发送复试通知，所以收到复试通知并不代表能收到拟录取。

*关于优营的发放，不建议rank相对较低（低于20%）的学生报考集成电路工程专业，面试结果与bg强相关，与面试回答情况相对较小，不容易候补上，请报考的同学慎重考虑。*
*以上评分标准均为个人猜测，不代表电子学院官方的评分标准，仅供参考。*
