# 复旦大学未来信息创新学院预推免

## 基本信息
复旦大学未来信息创新学院（原信息科学与工程学院）主要设有电子科学与技术研究院、光电科学与工程研究院、信息与通信工程研究院、光电研究院以及空间互联网研究院五大研究院，并拥有电子科学与技术、信息与通信工程和光学工程三大A+学科。

需要明确的是，硕士和博士的选拔逻辑有显著差异：
1. **硕士生**：采取**强com（委员会制）**模式。硕士主要设有新一代电子信息技术、人工智能、通信工程、集成电路产业专项班和工程硕博改革专项这五大研究方向，并且归属于（085400）电子信息专业。门槛略低于复旦大学微电子学院（现集成电路与微纳电子创新学院），笔者专业排名12.5%并成功入选硕士预推免。
2. **直博生**：采取**弱com（导师制）**模式。直博入营名额多但需要提前联系老师，能否入营基本取决于老师意愿，但具体录取还是由导师决定。

## 考核环节
### 1. 硕士考核
硕士生的考核流程：
- **材料准备**：笔者在收到的预推免复试通知邮件中，获悉了需要准备的材料包括：报到时需要身份证和学生证以及6份纸质版简历，面试中需要准备10分钟以内的个人介绍PPT和2分钟左右的英文版自我介绍。（注：PPT需自行准备U盘在考场现场拷取）
- **时间**：20分钟左右
- **地点**：复旦大学江湾校区交叉学科二号楼
- **面试**：首先，老师会对学生进行英文测试，具体内容为提出英语问题并要求学生回答，笔者被问到的时用英文简要介绍自己并具体介绍一个自己感兴趣的课程或是项目。其次，学生开始对照PPT进行详细的自我介绍，这里最好把时间控制在10分钟以内并且内容不要过于复杂，老师也不希望听到过于冗长的内容。自我介绍完成后，现场的老师可能会根据他们感兴趣的项目对学生进行提问，或者针对老师自己的研究方向提问学生。最后，老师也可能会针对学生的个人情况进行询问，比如你的个人兴趣、来自哪里等等。（注：面试现场会有一个20分钟的倒计时，注意把握时间）

### 2. 直博考核
笔者未报名复旦大学未来信息创新学院的直博预推免，考核流程暂不了解。

## 优营
2026年复旦大学未来信息创新学院的复试通过基本为铁offer，即在复旦大学预推免系统上查询到复试通过即可在最终的教育部研招网上进行填报。这是笔者的预一优，也是笔者的最终去向。
