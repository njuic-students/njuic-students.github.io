# 浙江大学软件学院预推免

## 基本信息
浙江大学软件学院，简称“浙软”，是华五院校中水平不错但不太出名的计算机类学院。如果想转码，浙软的直博算是一个比较不错的选择。

同样，浙软的硕士需要经过机试和面试，据说机试非常之难，因此对于集成的同学来说，非常有挑战。

浙软的老师中，有不少的研究方向是偏AI Infra和计算机系统方向的，因此对于想做数字和架构、系统方向的同学来说，选择浙软中做计算机系统的老师直博，是一个不错的选择，而且就目前而言，系统方面毕业的薪资也是要明显高于同档次水平的数字IC的岗位的。

## 直博考核内容
只有面试环节，需要准备5-8分钟的PPT。流程如下：
- 先会进行抽签，决定考察你的计算机专业的专业课题目（他们有一张题目表，从上面选）。
- 在PPT讲解的前几页，如介绍学业成绩和个人背景的部分，使用英文，作为英文部分的考核，随后继续使用中文讲解项目经历和后续内容。
- PPT讲解结束之后，老师会提问刚才抽签抽到的专业课，可能是计算机网络、操作系统、数据结构与算法、计算机组成原理等课程的题目，几乎都很难，计算机科班生也很难回答的很好，因此作为跨专业的我们，不用有压力，说自己没学过这门课就行（但是计组的题目不会就不应该了，毕竟你要做系统和偏底层的/软硬件交叉的方向），老师不会因为专业课问题刁难。
- 接下来就是项目提问，可能涉及一些具体的技术细节，还有一些其他的宽泛的问题，例如，你觉得你的硬件背景在计算机系统的研究中有什么帮助，Codex已经能写的比你好了，你觉得你未来能发挥什么作用。

## 预录取
2026年的预推免很晚，在19号，20号晚上出结果。对于直博，提前联系好老师，确认好意向的话，基本就没问题。
