# 岗位要求篇

不同产业链环节的岗位，对技能、学历、项目经验的要求差异极大。本篇从整个产业链的全局出发，逐一拆解各方向的准入门槛与面试官的核心考核点。
下面讨论的都是本硕阶段，对于博士而言，无论是架构、数字IC、AI infra，还是模拟射频IC、器件工艺等方向，发表论文与相关企业的对口程度，是最重要的，优秀且对口的论文，是提高博士身价的最好武器。
---

## 一、通用基础 —— 无论做哪个方向都要有的底子

### 1.1 课程基础

集成电路各岗位对课程基础的要求高度重叠，以下是最核心的几门：

| 课程 | 重要性 | 关联方向 |
|------|--------|----------|
| **半导体物理 / 器件物理** | 极高 | 所有方向均需理解 MOS 管基本原理（阈值电压、亚阈值、短沟道效应等）。器件/工艺方向要求深入掌握。 |
| **数字集成电路设计** | 极高 | 数字前端/后端/验证的基础，CMOS 逻辑门、时序、功耗分析。 |
| **模拟集成电路设计** | 极高（模拟方向） | 运放、电流镜、带隙基准、频率补偿。模拟方向的核心课程。 |
| **数字电路 / 逻辑设计** | 高 | 组合逻辑、时序逻辑、状态机、Verilog。数字岗的敲门砖。 |
| **信号与系统** | 高 | 所有需要频域分析的岗位，尤其模拟/射频/混合信号。 |
| **计算机体系结构** | 高 | 数字前端/架构/SoC 方向的加分项。理解流水线、Cache、总线。 |
| **电磁场与电磁波** | 中高 | 射频/高速数字/封装方向。 |
| **C/C++ / Python / 脚本** | 高 | EDA 开发/ATE 测试/数据分析。数字岗也需要 TCL/Perl 脚本能力。 |

### 1.2 GPA 到底有没有用？

分情况讨论：

- **芯片设计岗（尤其大厂）**：GPA 不太管用。面试官更关心你有没有流片经验、会不会写 RTL、EDA 工具熟不熟。你就算模电考满分，没画过版图、没跑过 DRC/LVS，照样过不了面试。当然，GPA 太低（比如不到 3.0）确实说明态度问题，但过了基本门槛后，0.1 的差距毫无意义。
- **制造/设备/材料岗**：部分国企、研究所会卡 GPA，但也主要是第一轮简历筛选时用。社招基本不看。
- **考公/选调/国企**：GPA 有参考价值但不是决定性因素，学历档次和笔试面试成绩更重要。

**核心观点**：集成电路是典型的工程学科，公司招你来是要解决实际问题的——能不能独立完成一个模块的 RTL 设计、能不能画好一个运放的版图、能不能用 UVM 搭验证平台。这些能力没有一个是通过刷高绩点获得的。

### 1.3 学历要求

| 产业链环节 | 学历门槛 | 说明 |
|------------|----------|------|
| **数字前端/后端设计** | 硕士为主，优秀本科生可 | 海思/平头哥等大厂基本卡硕士，但有过流片项目经验的优秀本科生有机会 |
| **模拟/射频设计** | 基本要求硕士 | 培养周期长，本科课程深度不够。极少有本科直接做的 |
| **验证** | 硕士为主，本科较多 | 验证岗位需求量大，对学历相对宽容 |
| **版图设计** | 本科即可 | 少数硕士也可以做，对动手能力要求高 |
| **EDA 开发** | 硕士为主 | 算法岗基本要求硕士以上 |
| **制造（PIE/PE/YE）** | 本科起步 | 硕士有加分但不显著 |
| **设备/材料** | 本科起步 | 博士在研发岗有较大优势 |

## 二、芯片设计方向 —— 最看项目经验的方向

### 2.1 数字前端设计

**硬性要求：**
- 熟练掌握 Verilog/SystemVerilog，能独立写出可综合的 RTL 代码
- 理解时序概念（setup/hold、clock domain crossing、复位策略）
- 至少使用过一种主流仿真工具（VCS/ModelSim/QuestaSim）
- 理解 AMBA 总线协议（AXI/AHB/APB）者优先

**面试重点：**
- 项目经历是第一优先级。面试 90% 时间在聊你做过什么项目
- 如果没有流片经历，至少要有一个完整的 RTL 到综合的设计项目
- 手撕代码：写一个异步 FIFO、状态机、跨时钟域同步器、arbiter 等
- 八股文：跨时钟域处理方法、低功耗设计技术、流水线原理

**本科生能不能做？** 能。数字设计是 IC 方向中对本科生最友好的细分方向之一。关键是你有没有主动学 Verilog、有没有自己搭过项目。学校的课程设计（用 FPGA 点个灯、跑个数码管）在面试官眼里约等于什么都没做过。

### 2.2 数字后端/物理设计

**硬性要求：**
- 熟悉 Innovus 或 ICC2 的基本操作
- 理解时序分析（STA）、时钟树综合（CTS）、布局布线（Place & Route）的基本概念
- 理解功耗分析（IR drop、EM）的基本概念
- 有后端设计相关课程项目或实习

**面试重点：**
- 时序收敛的经验（setup/hold violation 怎么修）
- 物理验证（DRC/LVS）的经验
- 对深亚微米工艺效应的理解（OCV、AOCV、POCV）

数字后端是设计岗中加班最多的方向之一（流片前连续加班是常态），但也因此需求量极大，入行门槛低于前端设计。

### 2.3 模拟IC/射频IC设计

**硬性要求：**
- 扎实的模拟电路基础（运放、电流镜、带隙基准、频率补偿、噪声分析）
- 熟练使用 Cadence Virtuoso（Schematic + Layout）
- 有完整的模拟模块设计经历（从 schematic 到 layout 到后仿）
- 射频方向额外要求：ADS/HFSS、电磁场基础、Smith 圆图

**面试重点：**
- 手算运放的增益、带宽、相位裕度、噪声
- 解释某个模拟模块的设计考量（如带隙基准的温度系数优化、LDO 的稳定性补偿）
- 版图技巧：匹配、寄生优化、latch-up 防护

**特别说明：** 模拟设计培养周期长（通常 3-5 年才能独立做模块），但经验壁垒高、越老越值钱。模拟设计面试中，**是否独立完成过 tape-out** 是最重要的区分项。目前模拟岗的门槛越来越高，建议在研一甚至大四就开始跟着靠谱的课题组做项目。

### 2.4 数字验证

**硬性要求：**
- 掌握 SystemVerilog 验证语言（constraint random、coverage、assertion）
- 掌握 UVM 验证方法学（sequencer/driver/monitor/scoreboard 架构）
- 有使用 UVM 搭过验证平台的项目经验
- 理解覆盖率驱动的验证流程（code coverage / functional coverage）

**面试重点：**
- UVM 各个组件的职责和通信机制（TLM port）
- 覆盖率驱动的验证策略
- 实际项目中你验证了什么、怎么定的验证计划

验证是目前 IC 行业中**供需缺口最大**的方向之一。设计验证比通常接近 1:1 甚至 1:2。对于想进入数字 IC 但设计岗竞争不过的同学，验证是性价比极高的切入点。

## 三、EDA 开发方向

**硬性要求：**
- 扎实的 C++/数据结构/算法基础（对标互联网后端开发的编程能力）
- 了解芯片设计流程（综合/布局布线/时序分析/物理验证至少其一）
- 最优化理论、图论、计算几何等数学基础有加分
- 硕士及以上学历

**面试重点：**
- 编程能力（LeetCode 中等题水平）
- 对底层算法的理解（图划分、布局优化、SAT 求解等）
- 如果应聘国产 EDA 公司，对国产替代的理解和认同也是考核维度

EDA 开发是 IC 行业中最不卷且薪资尚可的方向。复合背景（计算机 + IC）是核心竞争力。

## 四、制造（Fab）、设备、材料方向

### 4.1 制造（Fab）

| 岗位 | 核心要求 |
|------|----------|
| **PIE** | 全面的器件物理和工艺流程理解，SPC/DOE 等统计方法，英语好（写报告/对接海外客户）。博士有明显优势。 |
| **PE** | 对应工艺模块的基础知识（光刻原理/刻蚀化学/薄膜生长机理等）。本科起步，更多靠 Fab 内部培训。 |
| **YE** | 统计基础扎实（Python/R 数据处理），缺陷分析和良率建模。 |
| **EE** | 机电一体化/自动化背景，PLC 编程，动手能力。 |

**面试特点：** Fab 方向的面试偏重基础理论和学习能力，不像设计岗那样要求有具体项目产出。面试官更关心你能不能适应 Fab 的工作节奏（倒班、on call），而不是你已经掌握了多少技能。

### 4.2 设备与材料

- **设备研发**需要多学科交叉：机械、电气、光学、等离子体物理、软件控制。硕士是基本门槛
- **材料研发**偏重化学/物理/材料学基础，博士优势明显。面试更看重发表论文的质量和方向匹配度
- **应用工程师**（设备 AE / 材料 AE）：技术门槛低于研发，但需要较强的沟通能力和出差适应性

## 五、如何准备 —— 针对性的能力建设

### 5.1 设计方向：流片项目 > 竞赛 > 课程设计

集成电路设计岗最看重的就是**你有没有真正做过东西**。优先级排序：

1. **流片经历**（即使只是一个简单模块）：碾压级竞争优势。哪怕流的是 MPW（多项目晶圆），只要参与了全流程（设计→仿真→版图→后仿→signoff），面试官就会非常认可
2. **FPGA 项目**：数字方向的次优选择。完整实现过一个 SoC（哪怕在 FPGA 上）也是非常有竞争力的
3. **全国大学生集成电路创新创业大赛（集创赛）**：有分量的竞赛经历，尤其是拿了奖的
4. **课程设计深入版**：把课设做到远超要求的深度，比如数字电路课设做成了带流水线的 RISC-V 处理器
5. **企业实习**：去设计公司做芯片设计实习生是最直接的加分方式

### 5.2 对比：论文和项目哪个重要？

在 IC 行业，**项目经验远大于论文**，这和 AI 行业截然不同。原因很简单：IC 设计的产出是芯片，不是 PDF——能否成功 tape-out、芯片回来后能不能正常工作，这些没法靠"水论文"来替代。面试官要的是一个能上手画版图、写 RTL、跑仿真的工程师，不是一个擅长灌水的论文机器。

但对于器件/材料方向，论文的重要性相对高一些，因为这类岗位的研究属性和学术界的关联更紧密。

### 5.3 实习的价值

IC 行业的实习有特殊性：芯片公司对设计实习生通常只能安排一些不涉及核心 IP 的工作（如验证环境的搭建、外围模块设计）。真正能参与核心设计的实习机会不多。因此：

- **设计方向的实习**：不一定要追求大厂 title。能真正上手做东西的小公司实习 > 去大厂打杂。只要能攒出"我独立设计了xx模块并参与流片"这样的经历，面试时的底气就完全不同
- **制造/设备方向的实习**：FAB 的产线实习非常宝贵，能直接接触工艺和设备，是进入 Fab 行业的标准路径
- **EDA 方向的实习**：门槛较高，建议在研究生阶段通过校企合作项目进入

## 六、面试全流程拆解

IC 岗位面试通常分 2-3 轮技术面 + 1 轮 HR 面。

### 6.1 一面（基础面）：筛基本功

- **设计岗**：基础电路知识 + 简单 coding 题（写 Verilog 模块 / 手算运放参数）
- **EDA 岗**：数据结构与算法（LeetCode 中等难度）+ 基本 EDA flow 概念
- **Fab/设备岗**：器件物理基础 + 工艺常识

### 6.2 二面（项目面）：最关键的轮次

90% 的时间聊项目。面试官会深入追问：
- 你在项目中做了什么？为什么这么做？
- 遇到了什么问题？怎么解决的？
- 如果重新做一次，你会怎么改进？
- 项目的关键指标是多少？（功耗、面积、频率、噪声……）

**注意：** IC 面试的价值核心是"你解决了什么工程问题"，不是"你复现了什么算法"。你遇到了一个时序 violation 并修好了它——这就是价值。你在某个公开 benchmark 上跑了个更高的分——在手握 tape-out 记录的面试官眼里几乎不算什么。

### 6.3 三面（主管面/综合面）：看潜力和匹配度

- 你对这个方向的兴趣和理解
- 你的学习能力和成长潜力
- 你对行业趋势的判断（加分项）
- 团队协作和沟通能力

### 6.4 HR 面

主要确认薪资期望、入职时间、稳定性。IC 行业 HR 面刷人的概率远低于互联网大厂。

## 七、总结：集成电路行业求职的核心逻辑

| 产业链环节 | 最看重的 | 入行门槛 | 本科生友好度 |
|------------|----------|----------|-------------|
| 数字前端 | 项目/流片经验 | 硕士为主 | ⭐⭐⭐ |
| 数字后端 | EDA 工具熟练度 | 硕士为主 | ⭐⭐⭐ |
| 模拟/射频IC | 流片 + 电路功底 | 硕士起步 | ⭐ |
| 验证 | UVM 平台搭建 | 硕士/本科 | ⭐⭐⭐⭐ |
| 版图 | 工具操作 + 工艺理解 | 本科 | ⭐⭐⭐⭐⭐ |
| EDA 开发 | 编程 + 芯片 flow | 硕士 | ⭐⭐ |
| 制造（PIE/PE） | 器件物理 + Fab 实习 | 本科 | ⭐⭐⭐ |
| 设备/材料 | 专业对口 + 论文/专利 | 本科/硕博 | ⭐⭐⭐ |

**最后一条建议：** 集成电路行业是典型的"经验型"行业——你的价值随着参与过的项目数量和质量而递增。与其纠结学校排名和绩点，不如尽早进实验室、尽早参与流片或实际工程项目。在面试官眼里，一个参与过 tape-out 的本科生，比一个只会刷题考高分的硕士生有价值得多。
