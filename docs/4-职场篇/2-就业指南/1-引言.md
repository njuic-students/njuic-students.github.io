# 引言

关于求职就业这一块，一直都是比较敏感的话题。一方面，这和钱直接挂钩，很大程度上决定每个人的命运；另一方面，无论在学校里读了多少年书，学到了什么，学历怎样，最终都要找工作，是所有人都必须要面对的。

集成电路行业近年来在国家政策和资本推动下高速发展，但同时也是一个周期性很强的行业——芯片设计、制造、封测、设备材料等各环节的就业形势和薪资水平差异巨大，选对方向和时机至关重要。

当然，千人千面，彼之甘露，吾之砒霜。有人渴望投身一线芯片设计公司追求高薪和成长空间，也有人对初创芯片公司的不确定性和加班文化心存顾虑。基于每个人的立场和背景，对于同样的就业岗位有不同的态度和看法，这都是很正常的。因此，为了避免可能会出现的冲突，需要做出几点声明：

1. **理性人假设**。人在做决策时，会冷静、自利、逻辑清晰地选择对自己最有利、收益最大、成本最小的方案。接下来对于某些事物的分析将遵循这一假设，决策是冷酷无情的、直击核心利益的，这固然会使得某些人不太舒服，因为每个人都有自己的价值观，利益至上的原则会和某些价值观产生强烈冲突。例如，关于读研选方向和导师这一重大人生选择，如果秉持利益至上的原则，数模混合芯片设计、高性能计算架构等方向当前市场需求旺盛，往往薪资优厚。然而，现实决策是复杂的，我们往往也会考虑导师人品、指导风格、实验室资源、个人研究兴趣等要素，不可能狭隘地让"薪资前景"这一要素占据 100% 的权重。千人千面，没法顾及所有人的实际情况，只能在后文中以客观的行业数据和市场规律为基准，向所有人展示尽可能清晰的信息。至于个人怎么选，那是个人要根据自己的实际情况综合考虑，每个人都有独一无二的路要走。如果后文中的某些内容让大家觉得被"冒犯"了，在这里说一声抱歉。社会的运行规律不以个人意志而发生改变，即使不认同，也只能将这些客观事实讲出来。当你连世界都没认识全面，又何谈改变呢？

2. **佛系更新**。就业这一块不是三言两语就能讲清楚的，事实上这是一个成体系化的东西，而这些经验或者技能几乎不可能在学校里学到。如果基于理性人的假设，大可不必花时间写这些内容，因为创作是消耗人的，而用 AI 生成又是不靠谱的。因此没办法花很多时间洋洋洒洒写很多内容，只能慢慢地持续更新。这也得感谢集成学院有一群热心的本科生，不仅自身优秀，而且还想着带着其他人一起变优秀，是他们一起推动了这个项目的落地实现，真正实现了为广大集成学院同学服务，贡献者名单详见[贡献篇](/7-贡献篇/3-贡献者名单)。

3. **所在层次**。本文面向的受众是集成学院在读学生（主要是本硕），而这些受众放在普罗大众中算是比较优秀的（名校 + 强专业 + 国家战略风口领域）。因此本文在分析问题时往往有更高的标准。例如，对于一个普通专业的普通研究生而言，月薪万把块就已经很不错了，而集成电路作为国家战略性产业，目前正处于国产替代和自主可控的关键时期，行业整体薪资水平处于工科前列。大家应该奔着行业第一梯队的薪酬目标去努力——无论是进入头部芯片设计公司、半导体设备龙头企业，还是选择稳健的国企/研究所路线，都属于值得认真规划的职业路径。
