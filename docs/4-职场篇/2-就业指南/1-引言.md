# 引言

关于求职就业这一块，一直都是比较敏感的话题。一方面，这和钱直接挂钩，很大程度上决定每个人的命运；另一方面，无论在学校里读了多少年书，学到了什么，学历怎样，最终都要找工作，是所有人都必须要面对的。

集成电路行业近年来在国家政策和资本推动下高速发展，但同时也是一个周期性很强的行业——芯片设计、制造、封测、设备材料等各环节的就业形势和薪资水平差异巨大，选对方向和时机至关重要。

本文面向的受众是集成学院在读学生（主要是本硕），而这些受众放在普罗大众中算是比较优秀的（名校 + 强专业 + 国家战略风口领域）。因此本文在分析问题时往往有更高的标准。例如，对于一个普通专业的普通研究生而言，月薪万把块就已经很不错了，而集成电路作为国家战略性产业，目前正处于国产替代和自主可控的关键时期，行业整体薪资水平处于工科前列。大家应该奔着行业第一梯队的薪酬目标去努力——无论是进入头部芯片设计公司、半导体设备龙头企业，还是选择稳健的国企/研究所路线，都属于值得认真规划的职业路径。
