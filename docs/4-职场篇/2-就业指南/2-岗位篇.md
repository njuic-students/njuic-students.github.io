# 岗位篇

集成电路产业链是当今全球最复杂、最长的产业链之一，涉及设计、制造、封测、设备、材料、EDA 等多个环节。要理解各类岗位的定位和前景，必须先对产业链有一个全局性的认知。

---

## 一、产业链全景

```
上游                            中游                          下游
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│  EDA / IP       │    │  芯片设计        │    │  终端应用         │
│  半导体材料      │ →  │  晶圆制造        │ →  │  消费电子         │
│  半导体设备      │    │  封装测试        │    │  汽车/工业/通信    │
└─────────────────┘    └─────────────────┘    └─────────────────┘
```

整个产业链的就业体量和薪资水平呈明显的梯度分布。以下从上游到下游，逐一介绍核心岗位。

---

## 二、芯片设计（IC Design）—— 就业容量最大，薪资最高

芯片设计是目前国内 IC 行业就业岗位最密集、薪资水平最高的环节，也是集成学院学生最主要的就业方向。

### 2.1 数字前端设计

| 岗位 | 核心技能 | 说明 |
|------|----------|------|
| **数字IC设计工程师** | Verilog/VHDL、SystemVerilog、总线协议（AXI/AHB/APB） | 负责 RTL 代码编写，将架构规格转化为寄存器传输级实现。是最广泛的数字设计岗位。 |
| **SoC 设计工程师** | AMBA 总线、NoC、ARM/RISC-V 集成、功耗管理 | 在 IP 层面做系统集成，将 CPU、GPU、NPU、接口 IP 等集成为一个完整 SoC。需要系统级思维。 |
| **芯片架构师** | 性能分析、PPA 权衡、领域专用架构（DSA） | 芯片设计的最高技术岗位，决定芯片的整体架构。通常需要 5-10 年以上经验，薪资天花板极高。 |

**典型雇主：** 海思、展锐、哲库（已关闭）、平头哥、壁仞、摩尔线程、寒武纪、地平线、黑芝麻，以及各类 AI 芯片和车规芯片创业公司。

### 2.2 数字后端设计

| 岗位 | 核心技能 | 说明 |
|------|----------|------|
| **数字后端/物理设计工程师** | Innovus/ICC2、时序收敛、功耗分析、物理验证 | 负责逻辑综合、布局布线、时钟树、时序收敛。是流片前的最后一道关卡，加班最多的芯片岗位之一，但需求量大且薪资可观。 |
| **DFT 工程师** | Scan Chain、ATPG、BIST、JTAG | 可测试性设计，在芯片中嵌入测试逻辑。岗位偏小众但非常稳定，人才缺口大。 |
| **封装设计工程师** | 2.5D/3D 封装、SiP、Chiplet 互连 | 先进封装是后摩尔时代的关键技术，Chiplet 架构的兴起让封装设计越来越重要。 |

### 2.3 模拟与混合信号设计

| 岗位 | 核心技能 | 说明 |
|------|----------|------|
| **模拟IC设计工程师** | 运放、带隙基准、LDO、PLL、ADC/DAC、Cadence Virtuoso | 模拟电路设计的门槛高于数字，需要扎实的器件物理和电路理论功底，培养周期长（通常 3-5 年才能独立设计），经验越老越值钱。 |
| **射频IC设计工程师** | 射频电路、电磁场、Smith 圆图、ADS/HFSS | 模拟设计中最难的方向之一，薪资在所有 IC 设计岗位中处于第一梯队。5G/6G 和卫星通信推动需求持续增长。 |
| **混合信号设计工程师** | 数模混合仿真、AMS 验证 | 连接数字与模拟世界的桥梁。ADC/DAC/PLL/SerDes 是核心模块。 |
| **电源管理IC设计工程师** | DC-DC、LDO、电荷泵、GaN 驱动 | 万物互联时代，任何电子设备都需要电源管理芯片。模拟方向中需求最大的子类之一。 |

### 2.4 芯片验证

| 岗位 | 核心技能 | 说明 |
|------|----------|------|
| **数字验证工程师** | SystemVerilog、UVM、断言、覆盖率驱动 | 验证工作量通常占芯片设计周期的 50-70%。供需关系紧张，缺口极大。入行门槛相对设计较低，是数字IC方向非常好的切入点。 |
| **FPGA 原型验证工程师** | FPGA 综合、时序约束、板级调试 | 用 FPGA 搭建芯片原型进行功能验证和软件提前开发。 |

### 2.5 模拟版图设计

| 岗位 | 核心技能 | 说明 |
|------|----------|------|
| **模拟版图工程师** | Virtuoso Layout、DRC/LVS、匹配/寄生优化 | 将模拟电路原理图转化为物理版图。纯本科即可胜任，是进入模拟 IC 方向的重要入口，发展路径清晰（Junior → Senior → Lead）。 |

## 三、芯片制造（Foundry / Fab）—— 投入最大，壁垒最高

芯片制造是 IC 产业链中资本壁垒和技术壁垒最高的环节，一座先进晶圆厂的投资动辄数百亿。国内在这一环节与台积电/三星的差距最大，但也是国家投入最集中的方向。

| 岗位 | 说明 |
|------|------|
| **工艺整合工程师（PIE）** | 负责整个工艺流程的整合优化，是 Fab 中最核心的技术岗。需要全面理解器件物理和工艺模块。发展空间大，薪资在 Fab 岗中最高。 |
| **工艺工程师（PE）** | 负责单一工艺模块（光刻/刻蚀/薄膜/扩散/注入/CMP 等），偏执行和问题解决。需求量大，本科起步。 |
| **良率工程师（YE）** | 分析缺陷、提升良率，是 Fab 和客户之间的关键接口。需要较强的数据分析和统计能力。 |
| **设备工程师（EE）** | 维护和优化生产设备。工作环境在洁净室，24 小时 on call，是最辛苦的 Fab 岗位之一，但基础薪资稳定且加班费可观。 |

**典型雇主：** 中芯国际（SMIC）、华虹、长江存储、长鑫存储、台积电（南京/上海）、三星（西安）、Intel（大连）、华润微、粤芯、积塔。

**趋势判断：** 随着美国对先进制程设备的出口限制持续加码，国内成熟制程（28nm 及以上）的产能扩张需求巨大。但是请注意，成熟制程虽然成本低、收益大，但如果 AI 带来的需求端潜力不及预期或者未来出口限制扩大导致禁止成熟制程出口，那么会造成产能过剩，已经有部分猎头表示不建议去没有央企背景的代工厂和应届生盲目往fab厂拥挤。以目前来看，设计岗仍然是整个产业链中利润最大的，对于集成学院的学生来说应该优先考虑设计岗。

---

## 四、封装测试（Packaging & Testing）

先进封装是后摩尔时代的核心战场之一。Chiplet、3D IC、异构集成等技术的兴起让封装从"低端劳动"变成了"先进技术"。

| 岗位 | 说明 |
|------|------|
| **先进封装工程师** | 2.5D/3D、Chiplet、Fan-out、TSV、混合键合等。技术含量高，薪资在封测环节中最高。 |
| **ATE 测试工程师** | 使用自动测试设备（ATE）编写测试程序，筛选不良芯片。需求量大，需要编程能力。 |
| **封装设计工程师** | 与芯片设计后端紧密协作，负责基板设计、信号完整性/电源完整性分析。 |

**典型雇主：** 长电科技（全球第三）、通富微电、华天科技、日月光（台湾/大陆）、安靠。

**趋势判断：** 先进封装正从产业链末端走向核心位置。TSMC 的 CoWoS 封装技术是 AI 芯片（H100/B200）产能瓶颈的关键。国产 Chiplet 标准（UCIe）的推进将带动封装设计岗位的需求增长。但要清醒认识到，封装的核心能力在地理和规模效应（当然摩尔定律走向极限后封装技术也是在进步的），意味着你未来的工作中可能需要长期蹲在工厂里，与设计岗的白领工作体验完全不同。

---

## 五、EDA 工具 —— "卡脖子"最严重的环节

EDA 是芯片设计的基础工具，但全球市场被 Synopsys、Cadence、Siemens EDA（原 Mentor）三巨头垄断 70% 以上。美国对 EDA 工具的出口管制使得国产 EDA 成为当前最紧迫的国产替代方向之一。

| 岗位 | 说明 |
|------|------|
| **EDA 软件开发工程师** | 开发逻辑综合、布局布线、时序分析、物理验证、电路仿真等工具。需要复合背景：计算机（算法/数据结构/C++） + IC 基础知识。薪资对标互联网大厂，且工作节奏相对稳定。 |
| **EDA 应用工程师（AE）** | 在客户端支持工具使用，需要深入理解芯片设计流程和客户需求。出差较多，但积累人脉快。 |

**典型雇主：** 华大九天（国产龙头）、国微集团、芯华章、概伦电子、广立微、合见工软。外资三巨头（Synopsys/Cadence/Siemens EDA）在国内也有大量研发岗位。

**趋势判断：** 国产 EDA 是政策重点扶持方向，但说实话几乎不可能做到国产替代，因为专利壁垒导致市面上的路径都被三巨头走完了，本质上要推倒重来，其次资本家不是傻子，哪怕有些没有被探索的路径，EDA的技术底层是通过问题的规约和建模来解决最优化问题，本质上EDA是在不断地解决离散数学或者连续的优化问题，从这个角度看，要想做出突破是很艰难的。但反过来想，三巨头的稳定统治意味着国内 EDA 的成长天花板极高，工作稳定且不卷，也是一个非常舒服的方向，相比于互联网，裁员风险小。缺点是对学历和背景要求较高。

## 六、半导体设备与材料 —— 国产替代的核心战场

### 6.1 半导体设备

光刻机、刻蚀机、薄膜沉积设备、离子注入机、清洗设备、检测设备……半导体制造所需的设备种类繁多，技术壁垒极高。

| 岗位 | 说明 |
|------|------|
| **设备研发工程师** | 机械/电气/光学/软件/等离子体等多学科交叉。设备工程师在无尘室工作，工作环境相对艰苦。 |
| **工艺应用工程师** | 在客户 Fab 端调试设备工艺参数。需要与客户紧密配合，出差频繁。 |

**典型雇主：** 北方华创（国内龙头）、中微公司（刻蚀）、上海微电子（光刻机）、盛美上海（清洗）、拓荆科技（薄膜/CVD）、芯源微（涂胶显影）、华海清科（CMP）。

### 6.2 半导体材料

硅片、光刻胶、电子特气、靶材、CMP 抛光液/垫、湿电子化学品、前驱体……每一种材料都是精细化工与半导体物理的交叉产物。

| 岗位 | 说明 |
|------|------|
| **材料研发工程师** | 高分子/有机化学/无机化学/物理化学背景。半导体材料的研发周期长、验证门槛高，需要耐心。 |
| **应用工程师** | 配合 Fab 客户验证和导入新材料。 |

**典型雇主：** 沪硅产业、立昂微（硅片）、南大光电、晶瑞电材（光刻胶/化学品）、雅克科技（前驱体）、安集科技（CMP 抛光液）、江丰电子（靶材）。

**趋势判断：** 设备和材料是国产替代逻辑最硬的方向——无论芯片设计公司怎么洗牌，Fab 产线的设备和材料需求永远在。但要注意，设备和材料企业的商业模式与芯片设计公司不同：重资产、长周期、低毛利率（相比设计公司），薪资结构也与设计公司有差距。

## 七、其他相关岗位

| 岗位 | 说明 |
|------|------|
| **芯片应用工程师（AE/FAE）** | 面向客户提供芯片选型、参考设计和技术支持。技术深度不如设计岗，但能积累广泛的行业人脉，转销售/市场/产品的路径通畅。 |
| **芯片产品经理** | 定义芯片规格、跟踪市场需求、管理产品生命周期。需要技术+商业双重能力，是技术和管理的交汇点。 |
| **芯片销售/市场** | 芯片销售是技术性销售（不同于快消品），需要有基本的技术理解力。半导体客户关系稳定，一旦形成 Design-in 就很难更换，因此销售岗位的积累效应明显。但是缺点是芯片销售本质上还是吃喝玩乐加客户关系，技术门槛不高，存在技术替代风险。 |
| **知识产权/专利工程师** | 半导体领域专利诉讼频发（尤其在海外市场），专利撰写、FTO 分析、专利布局等需求旺盛，适合有技术背景且偏好法律方向的同学。 |
| **行业研究/投资分析师** | 券商半导体分析师、PE/VC 硬科技投资。需要深度行业认知 + 财务分析能力。路径：通常需要 2-3 年产业经验后转型。 |

## 八、岗位选择的全局框架

总结一下，选择集成电路行业岗位时，可以从以下几个维度综合考量：

| 维度 | 高薪方向 | 稳定方向 | 高成长方向 |
|------|----------|----------|------------|
| **设计** | 数字IC设计、模拟IC、射频IC、架构 | 验证、DFT、版图 | AI 芯片、Chiplet 架构 |
| **制造** | 工艺整合（PIE） | 工艺工程师、良率工程师 | 先进制程（5nm 以下） |
| **封测** | 先进封装设计 | ATE 测试 | Chiplet/3D IC 封装 |
| **上游** | EDA 开发 | EDA AE | 国产 EDA 替代 |
| **设备/材料** | 设备研发 | 应用工程师 | 核心零部件国产化 |

**核心建议：** 对于集成学院的学生而言，如果条件允许，优先考虑芯片设计方向——利润最丰厚、天花板最高、工作体验最好。如果对设计不感兴趣或竞争激烈进不去，验证、EDA、先进封装设计是很好的次优选择。Fab 制造和设备材料方向建议在有清晰认知的前提下进入——它们更稳定但不那么"性感"，适合追求长期主义和工作生活平衡的同学。
