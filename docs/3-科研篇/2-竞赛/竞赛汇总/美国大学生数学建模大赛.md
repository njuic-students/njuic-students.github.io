# 美国大学生数学建模大赛

## 竞赛简介

美国大学生数学建模大赛通常简称“美赛”，由美国数学及其应用联合会（COMAP）主办，包括数学建模竞赛（MCM）和交叉学科建模竞赛（ICM）。比赛要求不超过3人的队伍在约4天内，从开放性实际问题中选择一题，完成问题分析、模型建立、计算验证和英文论文写作。

每年通常提供6道题：

- **MCM A题**：连续型问题；
- **MCM B题**：离散型问题；
- **MCM C题**：数据分析问题；
- **ICM D题**：运筹学与网络科学问题；
- **ICM E题**：可持续发展问题；
- **ICM F题**：政策问题。

参赛队只能选择其中一道题提交论文。比赛不仅考察模型是否复杂，更重视问题理解、假设合理性、结果解释、敏感性分析和英文表达。

::: tip 📌 信息更新
COMAP会逐年更新比赛时间、提交方式和AI工具政策。本文列出的具体时间以2027年赛事为例，报名前请再次查看[MCM/ICM官方页面](https://www.contest.comap.org/undergraduate/contests/mcm/)。
:::

## 参赛要求

- **参赛对象**：在比赛开始时仍具有学籍的本科生及以下学生，专业不限，可以是全日制或非全日制学生。
- **组队方式**：每队1-3人，所有成员必须来自同一所学校；每名学生只能参加一支队伍。
- **指导教师**：每队必须有一名Advisor完成注册。Advisor可以是本校教师、工作人员或学生，但比赛开始后不得参与解题。
- **报名费用**：2027年官方报名费为每队100美元，由Advisor在线完成注册和缴费。学校可以报名多支队伍。
- **比赛纪律**：比赛期间只能由队内成员讨论题目，可以使用书籍、论文、网站、数据库、软件等非人工资源，但所有资料和数据都应规范引用，不得向队外人员寻求解题帮助。
- **论文要求**：提交一份匿名PDF，正文中不得出现学生、指导教师或学校名称，只保留团队Control Number。2027年规则要求整份常规论文不超过25页，摘要页、目录、参考文献、附录和代码均计入页数。
- **AI工具**：允许谨慎使用生成式AI，但必须在正文中引用所用工具并说明用途，同时在论文末尾附上独立的`Report on Use of AI`。团队需要自行核验AI生成的事实、代码和参考文献；未如实披露可能被认定为学术不端。

比赛结果一般分为以下等级：Successful Participant、Honorable Mention、Meritorious、Finalist和Outstanding Winner，即通常所说的成功参赛奖、H奖、M奖、F奖和O奖。违反规则或论文存在严重问题的队伍还可能被评为Unsuccessful或Disqualified。


## 时间安排

美赛通常在北京时间1月底或2月初举行。2027年官方时间换算如下：

- **报名截止**：美国东部时间1月28日15:00，即北京时间1月29日04:00；
- **比赛开始**：美国东部时间1月28日17:00，即北京时间1月29日06:00；
- **停止修改**：美国东部时间2月1日20:00，即北京时间2月2日09:00；
- **论文提交截止**：美国东部时间2月1日21:00，即北京时间2月2日10:00；
- **结果公布**：计划于2027年5月8日公布。

每年日期都会变化，且官网使用美国东部时间。安排校内场地、订餐和提交论文时，务必自行复核时区，不要只参考往年的北京时间。


## 经验分享

下面是适合第一次参赛队伍的通用准备思路。

### 赛前准备

- **明确分工**：常见分工是建模、编程和写作，但三名成员都应理解核心模型。写作不能等到最后一天才开始，建模与论文应同步推进。
- **完成一次模拟赛**：选择一道往年题目，用完整的比赛时长走完选题、建模、计算、绘图和论文提交流程，比只学习模型算法更有效。
- **统一工具链**：提前确定Python、MATLAB或R等计算环境，并准备好Word或LaTeX模板、文献管理方式和图片导出规范。
- **补齐常用方法**：重点掌握数据清洗、回归与预测、优化、评价模型、网络分析、蒙特卡洛模拟，以及误差、敏感性和稳健性分析。无需追求模型数量，关键是能解释为什么采用该模型。
- **准备可信数据源**：熟悉政府、国际组织、学术数据库等可靠数据来源，并练习记录数据链接、访问日期和处理过程。

### 比赛期间

1. **先选题，再深入**：开赛后快速阅读全部题目，从数据可得性、模型熟悉度、工作量和创新空间四个角度比较。不要因为某道题看起来熟悉就立即锁定。
2. **先做可运行的基础模型**：第一天应尽快形成问题假设、变量定义和基础结果。在此基础上再增加约束、改进算法或扩展情景。
3. **让结果能够解释问题**：图表应服务于结论，模型参数要有现实含义。除了给出最优值或预测值，还要说明结果为何合理，以及对假设变化是否敏感。
4. **及时写论文**：每完成一个模块就补充相应的文字、公式和图表，并随时维护参考文献。最后一天主要用于整合、复核和压缩篇幅。
5. **重视摘要页**：官方明确强调摘要在评审中的重要性。摘要应简洁说明采用了什么方法、得到什么关键结果以及结论有何价值，而不是重复题目背景。
6. **留出提交缓冲**：停止修改前完成PDF导出，检查匿名要求、Control Number、页数、公式、图片、引用和文件名。不要把第一次上传留到最后几分钟。

一个可参考的节奏是：前6小时选题并确定框架；第一天完成基础模型；第二天完善算法和实验；第三天完成主体论文；最后一天集中处理摘要、敏感性分析、格式检查和提交。实际安排应根据题目和队伍特点调整。
