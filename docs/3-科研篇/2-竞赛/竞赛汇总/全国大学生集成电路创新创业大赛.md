# 全国大学生集成电路创新创业大赛

## 竞赛简介

全国大学生集成电路创新创业大赛，简称“集创赛”，是由工业和信息化部人才交流中心主办的全国性赛事。大赛面向集成电路产业实际需求设置企业命题，覆盖芯片设计、EDA、FPGA与嵌入式系统、芯片应用、测试、制造设备和材料等方向，强调工程实践、团队协作和成果展示。

比赛通常采用“初赛—分赛区决赛—全国总决赛”的三级赛制。初赛多以技术文档、设计作品或上机实测的形式进行；分赛区决赛和全国总决赛通常还包括现场答辩、作品演示和专家提问。不同企业命题使用的工具、开发板、提交材料和评分标准差异较大，选题前应完整阅读当届赛题说明。

::: tip 📌 信息更新
赛题、软硬件申请、提交格式和比赛地点每年都会调整。本文以第十届（2026年）章程为例，实际参赛时请以[大赛官网](https://univ.ciciec.com/)和对应企业命题群的最新通知为准。
:::

## 参赛要求

- **参赛对象**：集成电路、微电子、电子科学与技术，以及电子信息、通信、计算机、自动化、数学等相关专业的在校专科生、本科生、硕士研究生和博士研究生。
- **组队方式**：每队1-3名学生、1-2名指导教师，允许跨校组队。跨校组队时需要确定团队所属院校，获奖证书和组织奖统计均以该院校为准。
- **参赛组别**：
  - A组：团队成员全部为本科生及以下学历；
  - B组：团队中有一名或以上硕士、博士研究生。
- **选题限制**：除“集成电路芯创成果方向”外，每名学生原则上只能加入一个团队，每队选择一个企业命题；各赛题会单独规定允许报名的组别。
- **作品要求**：参赛作品应由团队独立完成。引用论文、开源代码或实验室已有成果时，需要取得许可并在技术文档、答辩PPT等材料中标明来源。
- **保密与知识产权**：部分企业会提供受限的软件、硬件和技术资料，参赛者应遵守赛题中的保密与知识产权条款，不要把群内资料或企业工具随意上传到公开仓库。

以第十届赛事为例，报名阶段每队缴纳300元押金，通过初赛后转为参赛费；交通、住宿等线下参赛费用一般需要自行承担。费用政策可能变化，报名前应再次核对当届章程。

## 时间安排

赛事一般从年初持续到暑假，完整周期约半年。第十届（2026年）官方章程给出的主要时间节点为：

- **1月-3月**：公布企业命题、组队报名和申请赛题软硬件，报名截止时间为3月31日；
- **4月中旬**：中期检查，统计作品进度；
- **5月7日前**：可选的校内选拔赛；
- **5月7日**：初赛作品提交截止，5月进行企业技术评审；
- **7月**：七大分赛区决赛，江苏高校属于华东赛区；
- **8月下旬**：全国总决赛。

初赛由命题企业专家进行线上技术评分。分赛区决赛通常综合初赛成绩和现场评审成绩确定赛区奖项及国赛晋级名单；全国总决赛则重点考察演讲汇报、作品演示和现场问答。具体时间、地点及是否线下举行，以当届通知为准。

## 经验分享

### 选题与组队

不要只根据企业名称或题目标题选题。首先下载赛题附件，检查是否具备所需的EDA工具、开发板、仪器和实验环境，再判断团队能否在几个月内完成。部分题目会要求申请指定硬件或参加培训，错过申请时间后很难补救。

三人队伍可以按“算法/数字设计—硬件实现与测试—文档与展示”进行初步分工，但不要完全割裂。负责答辩的同学必须理解核心架构、关键指标和实验方法，其他成员也要能处理现场演示中的突发问题。

如果团队成员都来自集成电路专业，可以优先考虑数字IC设计、FPGA、EDA或芯片测试等与课程联系较紧密的题目；芯片应用、机器人或视觉类题目则适合与自动化、计算机等专业的同学合作。

### 参赛流程与准备

1. **逐条拆解评分标准**：把评分项整理成任务表，明确哪些是基本功能，哪些是性能加分项，避免做了很多工作却没有对应评分点。
2. **尽早跑通最小系统**：收到工具或硬件后，先完成安装、授权、编译和基础通信测试。不要把环境配置拖到作品提交前。
3. **保留可复现记录**：使用Git管理代码，记录工具版本、参数、测试条件和关键实验结果。芯片设计类题目尤其要保存日志、波形、版图截图和PPA等指标。
4. **持续准备文档**：中期检查前就建立技术报告框架，边开发边补充系统框图、流程图和实验数据。最后集中补文档很容易遗漏设计依据。
5. **重视实测和鲁棒性**：演示前按照评分表反复测试，并准备备用线材、电源、工程文件和离线安装包。现场稳定完成基本功能通常比临时增加高风险功能更重要。
6. **模拟答辩**：提前准备简短版本和完整版本的汇报，围绕“为什么这样设计、指标如何测量、创新点在哪里、方案有什么局限”进行交叉提问。
