# 南京大学集成电路学院概况

## 学院概况

南京大学集成电路学院是南京大学在苏州校区首批建设的学院之一，于2022年正式挂牌。

一、历史底蕴深厚
南大集成电路学科最早可追溯至1956年中国首届五校联办半导体物理专业，学科根基深厚。

二、学科平台顶尖
**学科建制**：拥有全国首批“集成电路科学与工程”一级学科博士点及博士后流动站，入选“十四五”江苏省重点学科。
**科研平台**：获批建设“国家集成电路产教融合创新平台”、自旋电子器件与技术全国重点实验室、江苏省集成电路先进制程工程技术联合实验室等国家级和省部级平台。
**实验条件**：建有总面积近4000平方米的微纳工艺平台与设计实训云平台，满足从材料生长、器件加工到EDA线上实训的全链条科研需求。

三、研究方向前沿
学院重点建设六大方向，覆盖集成电路全产业链：
微纳电子科学：探索二维半导体、自旋电子等新型器件技术24。
器件与制造工艺：攻关后摩尔时代先进制程与新架构。
集成光电子：研发高能效发光、探测及功率器件。
材料与装备：发展大尺寸高质量外延材料及关键装备。
集成电路设计：聚焦大算力智能芯片与AI辅助电路设计优化。
封装与系统集成：突破先进封装与系统集成关键技术。
