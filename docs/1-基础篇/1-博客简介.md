# 博客简介

欢迎来到 **集成全家桶** —— 一个由南京大学集成电路学院同学自发创建和维护的民间 Wiki！

## 我们是谁

集成全家桶是一个面向南京大学集成电路学院（简称"集成"）全体同学的非官方知识共享平台。这里汇集了历届集成同学的学习经验、课程攻略、科研心得、职场见闻以及校园生活指南，旨在帮助每一位集成学子更好地度过大学时光。

:::tip 温馨提示
本站内容均由同学们自发撰写，仅代表个人经验与观点，不代表学院官方立场。如有疏漏或错误，欢迎指正和补充！
:::

## 本站内容导览

本站按照大学生活的各个方面进行分类，方便你快速找到所需信息：

| 板块       | 内容简介                                                                     |
| ---------- | ---------------------------------------------------------------------------- |
| **基础篇** | 博客简介、学院全景、师资百科 —— 帮助你快速了解集成的全貌                     |
| **学习篇** | 培养方案解读、各门课程攻略、升学（保研/考研/留学）经验 —— 学业路上的得力助手 |
| **科研篇** | 研究方向导航、竞赛概览 —— 带你走进科研的世界                                 |
| **职场篇** | 实习指南、求职经验 —— 为未来的职业发展做好准备                               |
| **生活篇** | 苏州衣食住行、校园生活指南 —— 让你的大学生活更加丰富多彩                     |
| **FAQ**    | 新生常见问题、学习科研常见问题 —— 你的疑惑这里可能已有解答                   |
| **贡献篇** | 贡献指南、贡献者名单 —— 欢迎你也来添砖加瓦                                   |

## 如何使用本站

- **侧边栏导航**：左侧边栏按照板块分类，点击即可展开查看各子项
- **全站搜索**：页面顶部的搜索框支持全站内容搜索，输入关键词即可快速定位
- **课程攻略**：每门课程的攻略通常包含基本信息、课程资料、经验分享三大板块，建议结合自身情况参考
- **资料下载**：关于课程的历年资料我们放置在[资源仓库](https://github.com/njuic-students/Resources)中。如遇到Github无法访问或下载速度太慢等问题，可访问[国内镜像](https://resources.sporeking.top/njuic-Resources)获取资源。（该镜像通过alist挂载在网盘上，如有访问问题请联系[sporeking](https://github.com/sporeking)）
